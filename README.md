# Commercial AI MVP Workspace

This repository contains commercial AI MVP web applications built as high-performance client-side solutions inspired by real freelance requests (Malt, etc.).

## 🚀 Applications in Workspace

1. **AI SEO & Marketing Content Generator** (`workspace/ai-seo-content-generator/`)
   - Malt Job Reference: #AI-SEO-2026-8921 | Estimated TJM: 500€ - 700€/day
   - Performance features: O(1) Map cache, single-pass word/keyword analysis, debounced event inputs.

2. **AI Customer Lead Scoring & Triage System** (`workspace/ai-customer-lead-scoring/`)
   - Malt Job Reference: #AI-LEAD-2026-3042 | Estimated TJM: 550€ - 750€/day
   - Performance features: Matrix-based evaluation lookups, memoized score calculation.

3. **AI Automated Code Reviewer & Security Auditing Tool** (`workspace/ai-code-reviewer-assistant/`)
   - Malt Job Reference: #AI-CODE-2026-7719 | Estimated TJM: 600€ - 800€/day
   - Performance features: Pre-compiled regex pattern matching, O(N) single-pass lexical scanning.
