## 🛠️ Getting Started

### Prerequisites
- Node.js >= 18
- `pnpm` package manager

### Run Verification Tests
```bash
pnpm test
```

### Build for GitHub Pages
```bash
pnpm run build
```

This generates compiled static web application assets inside `dist/`.
