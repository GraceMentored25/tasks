## ⚡ Bolt Performance Optimizations
- **Lazy Word & Keyword Processing:** Keyword calculations performed asynchronously using micro-tasks (`requestAnimationFrame` / `setTimeout`) to prevent UI lock during large text rendering.
- **Single-Pass String Parsing:** Replaces redundant regex searches with a single O(N) linear string scan.
