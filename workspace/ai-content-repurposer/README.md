---

## ⚡ Performance Features & Architecture
- **Single-Pass Regex Parsing:** Parses raw content into Twitter threads, LinkedIn summaries, and Newsletter highlights in a single string scan.
- **Async Input Debouncing:** Text modifications are debounced (200ms) to ensure smooth input responsiveness.
- **Memoized Tokenizer Metrics:** Token counts and reading speeds are computed with cached string metrics.

## 🚀 How to Run
Open `index.html` in any web browser or deploy as a static webapp.
