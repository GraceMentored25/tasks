## ⚡ Overview & Performance Focus

This MVP provides automated AI copywriting and real-time SEO scoring.

### Performance Highlights (Bolt ⚡ Optimizations)
- **Debounced Real-Time SEO Scoring**: Uses a 200ms debounce timer to perform word frequency, keyword density, and readability analysis on input events without slowing keystrokes.
- **Memoized Word-Count HashMap**: Optimized O(N) word frequency analyzer replacing nested regex scans.
- **Instant Template Generation**: Low-overhead outline generation.

---

## 🛠️ Key Features
1. **Target Keyword Density Tracker**: Instant visual density bars and warnings for over-optimization.
2. **AI Article Outline & Meta Generator**: Auto-generates H1/H2/H3 structures and meta titles.
3. **Readability & Length Benchmark**: Live word/character counts and estimated reading time.
