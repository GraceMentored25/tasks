# AI SEO Content Generator & Keyword Optimizer

> **Malt Job Reference:** "Développement d'un générateur de contenu SEO optimisé par IA" (Ref: MALT-892401)
> **Estimated Budget / Pricing:** €3,200 (5 days at €640/day TJM)

## Description
A commercial AI-powered web tool designed for digital marketers and SEO specialists to analyze text readability, keyword density, and generate SEO-optimized content with sub-millisecond response caching.

## Features
- **Real-time Keyword Density Analyzer:** Calculates word frequencies instantly using tokenized map structures.
- **AI Meta Description Generator:** Generates punchy title and meta tags based on extracted high-intent keywords.
- **Performance Optimization:** Features an LRU memoization cache for text analysis to prevent main-thread lag during active typing.
