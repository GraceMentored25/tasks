# Outil IA de Génération de Contenu SEO Automatisé

## Référence de l'offre
* **Source:** Malt - *"Création d'Outil IA de Génération de Contenu SEO Automatisé"*
* **Fourchette de prix moyenne:** 1 200 € - 3 000 €

## Description de l'application
Cette application Web MVP permet d'analyser un mot-clé cible, de générer la structure d'un article SEO (titre H1, sous-titres H2/H3, méta-description, paragraphes d'introduction), de mesurer en temps réel le score d'optimisation SEO (densité de mots-clés, lisibilité) et d'exporter au format HTML ou Markdown.

## Fonctionnalités & Optimisations
- **Performance Client (Bolt ⚡):** Calculateur de score SEO réactif avec écouteurs d'événements débouclés (debounce) pour éviter les re-calculs intempestifs du score lors de la frappe.
- **Export instantané:** Exportation en 1-clic aux formats Markdown / HTML.
