# AI Customer Support & FAQ Chatbot MVP

## Context Commercial & Prestation Freelance
* **Référence de l'offre Malt:** *Développement Chatbot Support Client IA & Automation FAQ*
* **Fourchette de prix moyen / Prestation:** **1 500€ - 3 500€**

## Description du Produit
Application MVP de Support Client basé sur l'IA pour l'automatisation du service après-vente et le traitement instantané des requêtes fréquentes.

## Fonctionnalités
* Assistant virtuel intelligent avec détection d'intention (Billing, Logistics, Tech Support)
* Rendu interactif ultra-rapide avec streaming de réponse
* Tableau de bord des métriques de performance client
* Module de test pour l'escalade vers un support humain

## Optimisations de Performance (Bolt ⚡)
* **In-Memory Query Cache:** Évite le re-traitement des requêtes identiques (< 2ms de temps de réponse).
* **Streaming avec `requestAnimationFrame`:** Fluidité parfaite du rendu textuel sans bloquer le thread principal.
* **Délégation d'événements:** Réduction de l'empreinte mémoire sur les boutons d'action rapide.
