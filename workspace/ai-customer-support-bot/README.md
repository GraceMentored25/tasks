# Bot Support IA Client (AI Customer Support Bot)

> **Malt Reference:** "Création Bot Support IA Client / Knowledge Base QA Bot"
> **Prix moyen sur le marché (Freelance Malt):** 3 000 € - 8 000 €
> **Déploiement:** GitHub Pages Ready (Fichiers statiques index.html / app.js / CSS)

## Description
MVP d'agent conversationnel IA pour le service client. Permet d'analyser les requêtes des clients en temps réel, de rechercher instantanément dans une base de connaissances vectorisée fictive et de répondre en langage naturel.

## Performance Optimization (Bolt ⚡)
- **Memoization cache:** Indexation instantanée des requêtes similaires sans recalcul.
- **Event Delegation:** Écouteurs d'événements centralisés sur le conteneur principal pour réduire la mémoire.
- **Debounced typing indicator:** Préviens les re-rendus intempestifs du DOM pendant la frappe utilisateur.

## Déploiement GitHub Pages
1. Pousser le dossier sur la branche principale (`main`).
2. Aller dans `Settings > Pages` sur GitHub.
3. Sélectionner `Source: Deploy from a branch` et choisir la racine ou `/workspace/ai-customer-support-bot`.
