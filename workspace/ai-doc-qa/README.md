# AI Document & PDF Analysis Assistant (`ai-doc-qa`)

## 📋 Commercial Job Reference
- **Platform Reference:** Malt - *Assistant IA d'analyse de documents PDF & Synthèse automatisée (SaaS / FinTech / Legal)*
- **Average Daily Rate (TJM):** 550€ - 750€ / jour
- **Estimated Project Budget:** 3 500€ - 5 000€

## 🚀 MVP Description
An interactive client-side AI document QA and text analysis assistant.
Users can upload text, select sample contracts or financial reports, generate instant executive summaries, perform semantic Q&A queries, and extract key action items.

## ⚡ Bolt Performance Optimizations
- **In-memory Search Indexing:** Paragraphs and sentences are pre-indexed into memoized token maps for instant O(1) query matching.
- **Cached Q&A Responses:** Answer lookup results are cached using query hash keys to eliminate redundant computations.
