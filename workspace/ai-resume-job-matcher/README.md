# AI Resume & Job Description Matcher (ATS Scoring)

> **Malt Job Reference:** "Outil IA de screening et matching CV / Offres d'emploi ATS" (Ref: MALT-732910)
> **Estimated Budget / Pricing:** €5,600 (7 days at €800/day TJM)

## Description
An enterprise recruitment tool that computes keyword matching and ATS (Applicant Tracking System) compatibility scores between resumes and job requirements in real-time.

## Features
- **Cosine Jaccard Similarity Engine:** Computes n-gram set overlaps between CVs and Job Descriptions.
- **Missing Skills Detection:** Identifies critical missing keywords required by ATS filters.
- **Fast Client-side Analysis:** Runs entirely in-browser without server roundtrips.
- **Performance Optimization:** Pre-indexed set operations for sub-5ms comparison times.
