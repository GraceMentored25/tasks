# AI SEO Content & Social Media Studio (`ai-seo-content-studio`)

## 📋 Commercial Job Reference
- **Platform Reference:** Malt - *Freelance AI Content Specialist - Generative SEO Article & Social Media Studio*
- **Average Daily Rate (TJM):** 600€ - 800€ / jour
- **Estimated Project Budget:** 4 000€ - 6 000€

## 🚀 MVP Description
A full-stack generative SEO content writer and multi-channel social post generator.
Features keyword density analysis, SEO score gauge, article structure generator (H1, H2, Key Takeaways), and automatic LinkedIn / Twitter content formatting.

## ⚡ Bolt Performance Optimizations
- **Debounced Input Analyzer:** Keyword frequency and SEO density calculations are debounced by 150ms to maintain smooth 60fps typing without UI thread lag.
- **Fast Single-Pass Tokenizer:** Word frequency counts use a single regex iterator `RegExp.exec()` avoiding multiple full-string splits.
