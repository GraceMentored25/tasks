# AI Resume & ATS Optimization Studio

> **Commercial Reference:** Malt Mission - *"Développement Tool IA - Générateur de CV & Lettres de Motivation"*
> **Target Market Pricing:** 3,500€ - 6,000€ per project / TJM: 500€ - 650€

## Overview
AI-powered client-side application for resume optimization, bullet-point AI enhancement, cover letter generation, and real-time ATS (Applicant Tracking System) keyword density scoring.

## Features
- Candidate profile and skill extractor
- Real-time ATS keyword matching with O(1) set complexity algorithm
- One-click bullet point rewrite with tailored action verbs
- Instant targeted cover letter synthesis
