# Générateur & Configurateur de Chatbot IA RAG Support Client

## Référence de l'offre
* **Source:** Malt - *"Intégration Chatbot IA RAG & Support Client Sur Mesure"*
* **Fourchette de prix moyenne:** 2 000 € - 5 000 €

## Description de l'application
Cette application Web MVP permet d'importer une base de connaissances (FAQ, documentation), de personnaliser les consignes (System Prompt), la tonalité et les paramètres du chatbot, puis d'interagir en direct dans une simulation de widget support client. Elle génère également l'Iframe/Widget d'intégration clé-en-main pour les sites E-commerce ou SaaS.

## Fonctionnalités & Optimisations
- **Performance Client (Bolt ⚡):** Indexation locale instantanée des fragments de connaissances (RAG simulation avec TF-IDF / Cosine Similarity local en sub-milliseconde) et réponses simulées ultra-fluides sans bloquer l'UI.
- **Export widget:** Code de widget HTML/JS auto-généré prêt pour déploiement.
