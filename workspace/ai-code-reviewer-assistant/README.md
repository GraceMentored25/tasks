- **Platform Reference:** Malt Freelance Listing - *"Expert IA / Python - Tooling IA revue de code & audit automatique"*

## Key Features
- **Automated Code Linting & Audit:** Fast client-side scan for security hazards, performance smells, and styling issues.
- **LLM Token Estimator:** Instant token count & cost estimate for sending code snippet to GPT-4o or Claude 3.5 Sonnet.
- **Refactoring Suggestions:** Actionable AI code transformation hints.

## Performance Optimizations (Bolt ⚡)
- **Non-blocking Rule Evaluator:** Asynchronous worker-style chunk evaluation for large code payloads.
- **Cached Token Parser:** Single-pass tokenizer with token memoization.
- **O(1) Map Rules Lookup:** Pre-compiled rule index maps for zero-latency lint execution.
