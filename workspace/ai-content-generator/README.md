# Générateur de Contenu Marketing IA (AI Content Generator)

> **Malt Reference:** "Générateur de Contenu Marketing IA / Copywriting Multi-canal"
> **Prix moyen sur le marché (Freelance Malt):** 2 500 € - 6 000 €
> **Déploiement:** GitHub Pages Ready (Fichiers statiques index.html / app.js / CSS)

## Description
Outil SAAS/MVP permettant aux équipes marketing de générer instantanément des posts LinkedIn, newsletters, articles de blog et accroches publicitaires à l'aide de modèles d'IA générative pré-optimisés.

## Performance Optimization (Bolt ⚡)
- **requestAnimationFrame Streaming Simulation:** Effet d'écriture en direct 60fps ultra fluide sans saccade ni blocage DOM.
- **Template Storage Cache:** Récupération instantanée des structures de templates précalculés.

## Déploiement GitHub Pages
1. Pousser le dossier sur la branche principale (`main`).
2. Configurer GitHub Pages sur le répertoire racine ou `/workspace/ai-content-generator`.
