# AI Customer Support Assistant & Ticket Classifier

> **Malt Job Reference:** "Assistant IA de tri et réponse automatique pour support client" (Ref: MALT-441209)
> **Estimated Budget / Pricing:** €4,500 (6 days at €750/day TJM)

## Description
An automated customer support copilot that analyzes customer inquiries, determines urgency and topic category, and suggests instant smart responses.

## Features
- **Smart Intent Classification:** Fast regex-based rule matching with fallback vector representation.
- **Urgency Scoring Algorithm:** Evaluates keywords in sub-milliseconds to mark tickets as High/Medium/Low priority.
- **Instant Response Templating:** Generates customizable reply drafts based on detected sentiment and issue category.
- **Performance Optimization:** Pre-compiled classification maps for O(1) response lookup.
